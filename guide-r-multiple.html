How to calculate the R multiple of MT5 trades

The R multiple of a trade is its net result divided by its initial risk. In MetaTrader 5, the initial risk is the loss the first entry would have made at its stop loss: read the stop loss from the entry deal (DEAL_SL), and ask MetaTrader for the money with OrderCalcProfit. The net result is profit + swap + commission + fee of all deals of the position.

Which stop loss to use

  • The entry deal carries the stop loss of the order that opened the position. That is the initial risk.
  • The exit deal carries the stop loss at the moment the position closed. After a trailing stop or a move to breakeven that is not the initial risk, so do not use it.
  • Changes in between are not stored in the history. If you set the stop loss only after entry, the entry deal has none; record it yourself while the trade is open, or use a fixed rule for such trades and mark them as estimates.

MQL5 code

// R multiple of a closed position: net result / initial risk (money at the entry deal's stop loss).
bool PositionR(const long position_id, double &r)
  {
   if(!HistorySelectByPosition(position_id)) return false;
   double net = 0, sl = 0, price = 0, volume = 0;
   string symbol = "";
   long   type = -1;
   for(int i = 0; i < HistoryDealsTotal(); i++)
     {
      ulong d = HistoryDealGetTicket(i);
      net += HistoryDealGetDouble(d, DEAL_PROFIT) + HistoryDealGetDouble(d, DEAL_SWAP)
           + HistoryDealGetDouble(d, DEAL_COMMISSION) + HistoryDealGetDouble(d, DEAL_FEE);
      if(type < 0 && HistoryDealGetInteger(d, DEAL_ENTRY) == DEAL_ENTRY_IN)
        {
         type   = HistoryDealGetInteger(d, DEAL_TYPE);
         sl     = HistoryDealGetDouble(d, DEAL_SL);        // stop loss of the opening order
         price  = HistoryDealGetDouble(d, DEAL_PRICE);
         volume = HistoryDealGetDouble(d, DEAL_VOLUME);
         symbol = HistoryDealGetString(d, DEAL_SYMBOL);
        }
     }
   if(type < 0 || sl <= 0) return false;                 // no stop loss: no R
   ENUM_ORDER_TYPE ot = (type == DEAL_TYPE_BUY) ? ORDER_TYPE_BUY : ORDER_TYPE_SELL;
   double risk = 0;
   if(!OrderCalcProfit(ot, symbol, volume, price, sl, risk) || risk >= 0) return false;
   r = net / -risk;
   return true;
  }

Pitfalls

  • Use the first entry. If you added to the position later, the initial risk still belongs to the first entry. Adding volume changes the money at risk, but not the plan you started with.
  • Conversion rates. For a symbol quoted in your account currency (for example XAUUSD on a USD account) OrderCalcProfit is exact. For crosses and JPY pairs it uses today's conversion rate, so the result can differ a little from the rate on the trade's day.
  • Costs belong to the result. Commission and swap are part of the net result, so a trade closed exactly at its stop loss has an R slightly below -1.
  • Breakeven. Treat a small band around zero, for example between -0.05R and +0.05R, as breakeven, so that rounding does not create wins and losses.
  • Netting reversals. A single deal can close one position and open the opposite one (DEAL_ENTRY_INOUT). Split it into two trades first.
