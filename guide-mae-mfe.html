How to measure MAE and MFE of closed MT5 trades

To measure MAE and MFE of a closed MetaTrader 5 trade, take the M1 bars from the minute of entry to the minute of exit. For a long trade, MAE = entry price minus the lowest low, and MFE = the highest high minus the entry price. For a short trade it is the other way round, measured on the ask. Divide by the initial risk to get MAE and MFE in R.

The steps

MQL5 code

// MAE and MFE (in price) of one closed position, from M1 bars.
// M1 bars are bid prices; for a short trade the ask is estimated as bid + bar spread.
bool PositionExcursion(const long position_id, double &mae, double &mfe)
  {
   if(!HistorySelectByPosition(position_id)) return false;
   string   symbol = "";
   int      dir = 0;
   double   entry = 0, vol_in = 0;
   datetime t_in = 0, t_out = 0;
   for(int i = 0; i < HistoryDealsTotal(); i++)
     {
      ulong deal = HistoryDealGetTicket(i);
      long  type = HistoryDealGetInteger(deal, DEAL_TYPE);
      if(type != DEAL_TYPE_BUY && type != DEAL_TYPE_SELL) continue;
      datetime t = (datetime)HistoryDealGetInteger(deal, DEAL_TIME);
      double   v = HistoryDealGetDouble(deal, DEAL_VOLUME);
      if(HistoryDealGetInteger(deal, DEAL_ENTRY) == DEAL_ENTRY_IN)
        {
         if(t_in == 0)
           {
            t_in = t;
            dir = (type == DEAL_TYPE_BUY) ? 1 : -1;
            symbol = HistoryDealGetString(deal, DEAL_SYMBOL);
           }
         entry += HistoryDealGetDouble(deal, DEAL_PRICE) * v;
         vol_in += v;
        }
      else t_out = t;                                   // last exit deal
     }
   if(vol_in <= 0 || t_out == 0) return false;         // still open
   entry /= vol_in;                                     // volume-weighted entry price
   MqlRates bars[];
   int n = CopyRates(symbol, PERIOD_M1, t_in - t_in % 60, t_out - t_out % 60, bars);
   if(n <= 0) return false;                             // no M1 history that far back
   double point = SymbolInfoDouble(symbol, SYMBOL_POINT);
   double lo = DBL_MAX, hi = -DBL_MAX;
   for(int k = 0; k < n; k++)
     {
      double ask_add = (dir < 0) ? bars[k].spread * point : 0.0;
      lo = MathMin(lo, bars[k].low + ask_add);
      hi = MathMax(hi, bars[k].high + ask_add);
     }
   mae = MathMax(0.0, (dir > 0) ? entry - lo : hi - entry);
   mfe = MathMax(0.0, (dir > 0) ? hi - entry : entry - lo);
   return true;
  }

To get money, ask MetaTrader what the move is worth: OrderCalcProfit(ORDER_TYPE_BUY, symbol, volume, entry, entry - mae, money) for a long trade. To get R, divide that money by the money at the initial stop loss (see How to calculate the R multiple).

Pitfalls

  • Edge bars. The first M1 bar includes prices from before the entry, and the last bar includes prices after the exit. For trades of a few minutes, especially around news, this can make MAE and MFE much larger than what the trade lived through. Mark these values as approximate, or use ticks.
  • Short trades. A short trade is closed at the ask, but M1 bars are bid prices. Adding the bar spread is an approximation.
  • The M1 history limit. MetaTrader keeps M1 bars only back to "Max bars in chart" (Tools > Options > Charts). Older trades get no bars; count them instead of guessing. A first request for old data can also start a download and return nothing; retry once, not for every trade.
  • Netting reversals. On a netting account one deal can close a position and open the opposite one (DEAL_ENTRY_INOUT). Split it into two trades before measuring.
  • Ticks instead of bars. CopyTicksRange gives the exact path where your broker keeps ticks, but each request takes a noticeable time. Use it for recent trades or in the background.
