Where others do more

  • Strategy Ledger Pro: correlation of daily results, prop limits, an execution report, what-if sizing and 11 languages.
  • EA Scorecard (free): Monte Carlo drawdown and a slippage estimate at no cost.
  • FX Blue: free public account pages that others can view, for MT4 as well as MT5 accounts.

Where EventOwl differs

  • An event tag on every trade: the major release near its entry or exit, matched by event code and corrected for daylight saving.
  • Fix windows: trades near the Tokyo or London fix are tagged. We did not find this in another analysis tool.
  • R, MAE and MFE in one row: next to the event, session and fix, with every input in the audit CSV.

EventOwl and EventOwl Pro 1.00 for MetaTrader 5. A read-only panel. It never opens, changes or closes orders. It describes what already happened and does not forecast.
